# NPC Hit Inspector 1.0.0

Новый отдельный тестер для ручного удара. Основан на проверенном перехватчике
`NPC-Hit-Diagnostic.lua`, с подробным отложенным обследованием объектов и наблюдением HP.
Старый диагностический файл и NPC GeneralHit не изменяются.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Probothotspot/Slap-battles-Teleport/main/NPC-Hit-Inspector.lua?v=1.0.0"))()
```

1. Запустить, подойти к NPC и ударить его **вручную**. Запись включена сразу.
2. Подождать 2–3 секунды. В статусе видны отдельные состояния структуры и HP.
   Для большой модели обследование может продолжаться дольше.
3. Нажать **Копировать всё** и прислать текст. Это краткое описание выбранного удара
   и JSON последних 12 записей. Стрелки выбирают удар для просмотра.
4. Если ничего не записалось, включить **Поймать все Remote на 10 секунд**, сразу
   ударить и повторить копирование. При отсутствии API копируется отчёт возможностей.

## Содержимое отчёта

- Фактический путь и класс RemoteEvent/RemoteFunction; FireServer/InvokeServer,
  порядок и типы аргументов, nil, вложенные таблицы, пути экземпляров.
- CallPreview с точным клиентским выражением вызова при полном поддерживаемом снимке.
  Этот код только показывается и не исполняется автоматически.
- Скрипт-инициатор через getcallingscript, доступный стек, executor и API,
  PlaceId/JobId, время, перчатка и Tool, положение/направление персонажа и камеры.
- NPC, здоровье, Humanoid, тип рига и дистанция до части тела в момент вызова.
- ObjectSurvey: дерево модели NPC, сам remote и текущий Tool при наличии свободного
  места среди корней. Каждая часть имеет полный путь, класс, индекс родителя,
  атрибуты/теги и доступные свойства своего класса.
- Позиция, CFrame, размеры, цвет/RGB, материал, прозрачность, коллизии,
  CanTouch/CanQuery, скорости сборки, масса; MeshId, TextureID, SpecialMesh,
  SurfaceAppearance, Decal, одежда, BodyColors, аксессуары; Motor6D/Weld/Constraint
  с путями Part0/Part1/Attachment; Humanoid, текущие анимации, SoundId,
  частицы, подсветки, промпты/детекторы, ValueBase и доступные свойства скриптов.
  Внешность описывается свойствами и ID ресурсов; изображение не создаётся.
- HealthObservation: локальные значения HP примерно через 0,2 / 0,5 / 1 / 2 секунды
  после захвата, фактическое время и разница с исходным значением. При зависшем кадре
  пропущенные моменты не выдумываются. Пересекающиеся наблюдения того же Humanoid
  отмечаются OverlappingCalls. Исчезновение Humanoid не считается смертью.

Свойства структуры читаются **позже вызова**, по кадрам: это не атомарный снимок
момента попадания. Для каждого узла указан SampledAfter. Недоступное свойство
отмечается в UnavailableProperties; это возможно из-за версии API или прав доступа.

## Ограничения и нагрузка

Скрипт только наблюдает исходящие вызовы. Не посылает, не повторяет и не изменяет
их, не наносит урон и не сканирует все ремоты по названиям для вызова.
Исходные результаты, nil, ошибки и yield InvokeServer сохраняются; ответ сервера
не записывается. Наличие пакета и последующее изменение HP не доказывают, что
именно этот пакет был принят сервером и вызвал урон.

Серверные исходники, валидация удара, кулдауны, точная точка контакта, сетевые байты
и невидимые клиенту объекты недоступны. Декомпиляции нет. Название способности
или серверный обработчик по одному имени remote не угадываются.

Перехват сохраняет быстрый ограниченный снимок аргументов, затем ставит подробности
в очередь. Обследование: до 16 узлов / мягкого бюджета 1,5 мс на Heartbeat суммарно,
256 узлов на запись, 12 уровней, 4 корня, 8 заданий, 8 секунд на задание,
16 исходных ссылок на объекты плюс remote/Tool, 32 активных наблюдения HP.
GetChildren одного объекта и JSON-кодирование не могут быть прерваны этим бюджетом;
при очень большой модели абсолютное отсутствие задержек не гарантируется.
Attributes/Tags ограничены 32 элементами, строки свойств — 1024 байтами.
Truncated, ReferenceLimit, ChildrenTruncated, DepthLimit и явные причины показывают
неполноту. Complete означает завершение обследования в пределах этих лимитов.

Базовый снимок: 20 записей/с с запасом 8, 16 аргументов, 180 узлов, 3 мс,
5 уровней таблиц, 30 элементов таблицы, строки 2048 байт. Копирование разрешено
до завершения обследования: оно экспортирует текущее состояние и не ждёт молча.

Используются прежние ключи ProbothotspotNPCHitDiagnostic / ProbothotspotNPCHitHook:
старое окно диагностики закрывается, собственный dispatcher переиспользуется.
Наш NPC GeneralHit выключается для чистого ручного теста. Другие автоматические
скрипты лучше остановить самостоятельно. При checkcaller вызовы executor исключаются.
Работоспособность перехвата зависит от executor; при отсутствии API GUI остаётся
доступным. Закрытие/перезапуск удаляют подписки, очередь и наблюдения.

Отчёт остаётся на устройстве до копирования; скрипт не загружает логи в сеть.

## Проверка

`lua NPC-Hit-Inspector-tests.lua` (Lua 5.4): проверки перехвата и исходного
вызова, GUI/буфера, путей, фильтров, реального кода отложенного обследования,
лимитов дерева/очереди, времён HP, пересекающихся вызовов, удаления Humanoid,
внешних свойств/ID мешей, атрибутов/тегов, перезапуска и очистки.
Это моделирование, а не запуск Slap Battles/Delta/Xeno.

Справочник API: https://create.roblox.com/docs/reference/engine/classes/Instance
и https://create.roblox.com/docs/reference/engine/classes/MeshPart .
