# Lantern AutoHit 1.0.0

Отдельная автоатака для NPC с Lantern. Используется структура фактически
наблюдавшегося клиентского пакета:

```lua
Players.LocalPlayer.Character.Lantern.Network:FireServer("Hit", targetPart)
```

Ник игрока, название модели врага, координаты, цвет и размер не закреплены.
Полный приватный диагностический отчёт не включён в репозиторий.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Probothotspot/Slap-battles-Teleport/main/Lantern-AutoHit.lua?v=1.0.0"))()
```

Экипировать **Lantern**, подойти к врагам и нажать **ON**. Скрипт не телепортирует
и не перемещает персонажа. При запуске выключен. После смерти ждёт нового живого
персонажа и вновь экипированного Lantern, если режим оставлен ON.

Фиолетовый переливающийся GUI перетаскивается за заголовок, сворачивается и
масштабируется под экран. Кнопка закрытия останавливает атаки и удаляет обработчики.

- **Лимит Hit/с:** 1–20, по умолчанию 4. Общий бюджет запросов, а не число
  подтверждённых ударов. Ограничение на один Humanoid — не чаще раза в 0,2 секунды.
- **Дистанция:** 1–30 студов, по умолчанию 8. Считается от Handle Lantern, либо
  HumanoidRootPart при отсутствии Handle, до ориентированного параллелепипеда
  части NPC по её текущим CFrame и Size. Внутри этого объёма расстояние равно 0.
  Крупный враг может быть рядом краем тела при удалённом центре; размер не изменяется.
  Это локальный критерий выбора, а не доказанная разрешённая дальность сервера.
- **Взмах ON** по умолчанию: при доступном Tool.Enabled запускается Tool:Activate,
  затем отправляется обнаруженный Hit-пакет во время AttackActive=true.
  Собственная активация отпускается через Tool:Deactivate примерно через 0,06 с.
  Между попытками активации минимум 0,55 с. Это пробные клиентские интервалы,
  а не подтверждённые кулдауны Lantern. Атрибуты и Tool.Enabled не подменяются.
- Если AttackActive отсутствует, используется явно непроверенное окно 0,06–0,4 с
  после собственного взмаха. Если атрибут есть и false, скрипт ждёт активный взмах.
- **Взмах OFF:** только `Network:FireServer("Hit", part)` в пределах выбранной
  дистанции/частоты. Этот режим позволяет сравнить прямую отправку; сервер может
  её игнорировать без необходимого игрового состояния.
- **Копировать диагностику:** текущий путь Network, цель/размер/дистанция,
  AttackActive, настройки, вызовы, взмахи, ошибки, наблюдаемое снижение HP и логи.
  При недоступном clipboard появляется выделяемое текстовое поле.

## Выбор целей

Только реальные BasePart с именем **CandyCorn** либо атрибутом **slappable=true**
в модели с живым Humanoid. Игроки, вложенные в их персонажей модели,
отдельные предметы без Humanoid и анимационные Pose с тем же именем исключаются.
CanQuery=false и CanCollide=false не исключают цель: пространственные запросы
Raycast/Overlap для индекса не используются.

Сначала выбирается ближайшая ещё не атакованная цель. В радиусе остальные цели
распределяются по давности последнего запроса, при равенстве — по расстоянию.
Несколько частей одной модели делят кулдаун её Humanoid. Перед отправкой заново
проверяются текущий персонаж, Lantern, Network, живая цель, её размер и расстояние.
Старый Tool/Remote после замены не используется. Требуется именно RemoteEvent
Network текущего Lantern; чужие Network и GeneralHit не вызываются.

Индекс обновляется при появлении/удалении объектов и периодически раз в 5 секунд.
Начальный обход по кадрам: максимум 512 шагов / мягкий бюджет 2 мс; ветки
KeyframeSequence и Pose пропускаются. Известные цели используются до окончания
полного обхода. Проверка целей имеет отдельный мягкий бюджет 1 мс / 128 частей,
с перемещающимся указателем при большом индексе. Один запрос за кадр, без
догоняющего залпа после зависания. При низком FPS, ограничениях взмаха или малом
числе целей фактическая частота ниже установленного предела.

## Проверка результата

**Отправлено** означает лишь возврат FireServer без ошибки. В предоставленной
исходной записи за две секунды HP врага не снизилось: сам формат вызова подтверждён,
успешный урон — нет. Нельзя по этому логу определить серверные проверки и причину
отсутствия урона. Ни поддержка всех NPC, ни дальность, ни частота сервером не доказаны.

**HP↓ (набл.)** — сумма локально замеченных снижений HP недавно атакованных NPC.
Это могут быть удары других игроков или другие причины. Исчезновение модели
не считается убийством. До 64 Humanoid наблюдаются в течение двух секунд после
последнего запроса; значения отслеживаются и после OFF до завершения окна.

Для первого запуска оставить 4 Hit/с, дистанцию 8 и Взмах ON, стоять рядом с врагом.
Если запросы идут, а результата нет, скопировать диагностику. Не считать высокую
частоту или успешный возврат функции доказательством принятия удара сервером.

Повторный запуск закрывает прежний экземпляр только этого скрипта. Другие
автоатаки лучше выключить вручную для чистого сравнения. При закрытии/смене сервера
свой цикл и анимации очищаются, собственный удержанный взмах отпускается.
Настройки/ON не сохраняются, автозагрузки на другом сервере в этом файле нет.
Скрипт не отправляет диагностические данные в сеть.

## Верификация

`lua Lantern-AutoHit-tests.lua` (Lua 5.4): формат двух аргументов и текущий получатель,
поворот/изменение размера, исключение игроков/анимационных поз, переключение взмаха,
окно AttackActive, отсутствие/изменение HP, замена Network/Tool/персонажа,
возрождение, ограничение работы на кадр, ошибки/повторный вход, реальный код GUI,
буфер, перетаскивание, сворачивание, повторный запуск и очистка.

Проверки выполняются в детерминированной модели. Живые Slap Battles/Delta/Xeno
здесь не запускаются; работу серверного урона нужно проверить в игре.

API: https://create.roblox.com/docs/reference/engine/classes/Tool
и https://create.roblox.com/docs/reference/engine/datatypes/CFrame .
