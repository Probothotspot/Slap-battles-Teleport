# Slap-battles-Teleport
Teleport Escanor Hub

## NPC GeneralHit

Отдельный скрипт `NPC-GeneralHit.lua` с фиолетовым GUI, перетаскиванием,
сворачиванием, ON/OFF и полем частоты 1–100 вызовов в секунду.
При запуске выключен; кнопки −/+ меняют частоту на один.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Probothotspot/Slap-battles-Teleport/main/NPC-GeneralHit.lua"))()
```

Частота **общая для всех целей**, а не на каждого NPC. Цели обходятся по кругу.
Скрипт ищет живые модели с Humanoid в реплицированном Workspace, исключает персонажей
игроков и вложенные в них модели. Имя Skeleton, папка Enemies, цвет и координаты
не закреплены. Перед каждым вызовом заново выбирается текущая часть тела: сначала
`["Right Arm"]`, затем варианты R15, HumanoidRootPart/Torso/Head. Если нужной части
ещё нет, такая цель временно пропускается. NPC без Humanoid не распознаются.

Отправляется только `ReplicatedStorage.GeneralHit:FireServer(part)` с одним аргументом.
GeneralHit ищется заново: если ивент исчез или был заменён, ON ждёт его появления.
После удаления/появления NPC индекс обновляется; первоначальный обход и сверка через
5 секунд выполняются порциями до 512 шагов / 2 мс за кадр, без общего GetDescendants.
Скрипт не ждёт окончания полного индекса, чтобы начать с уже найденных NPC.
Не загруженные сервером на клиент объекты не видны скрипту.

Максимум два вызова за Heartbeat: после зависшего кадра нет большого догоняющего пакета.
При низком FPS фактическая частота может быть ниже выбранной; GUI показывает фактические
вызовы за последнюю секунду и суммарное число вызовов, вернувшихся без ошибки.
Это **не подтверждение попаданий или урона**. Поддержка GeneralHit для конкретного NPC,
правильной перчатки, дистанции, кулдауна и других условий определяется сервером.
Скрипт не перебирает другие RemoteEvent и не телепортирует персонажа.

Повторный запуск закрывает прежний экземпляр. Закрытие окна, смена сервера или удаление
текущего PlayerGui останавливают цикл и очищают обработчики/анимации. ON не сохраняется
и автозапуска на другом сервере в этом отдельном скрипте нет.

Проверка: `lua NPC-GeneralHit-tests.lua` (Lua 5.4). 116 проверок модели покрывают
живые NPC/исключение игроков, частоту, новую конечность/ивент, исчезновение целей,
ограничение работы на кадр, повторный вход во время FireServer, настоящий код GUI,
поля/кнопки/перетаскивание, повторный запуск и очистку подписок.
Живой Slap Battles и Xeno/Delta этой моделью не заменяются и здесь не запускались.
